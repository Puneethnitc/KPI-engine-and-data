# KPI Intelligence prototype

The working application is in [`finalkpi/`](finalkpi/). That directory contains
the Python KPI engine, FastAPI backend, Next.js frontend, demo data, contracts,
tests, and project documentation.

For a new developer, start with
[`finalkpi/docs/TEAM_HANDOFF.md`](finalkpi/docs/TEAM_HANDOFF.md). Do not use the
`imports/` directory as application source; it is reserved for local import and
handoff artifacts and is ignored by Git.
